# calendar--py
This is a simple Python console application that displays the calendar for a specific month and year provided by the user. The project uses Python's built-in calendar module to generate and display the monthly calendar. It includes input validation to ensure users provide valid integers for both year and month.
## 📌 Features

- Accepts user input for year and month.
- Validates the input (positive integers, month between 1 and 12).
- Displays the calendar for the given month and year.
- Uses Python's built-in `calendar` module
